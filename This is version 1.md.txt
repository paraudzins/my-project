Git push iestatīšana

- Install Git ar komandu: winget install --id Git.Git -e --source winget  --nepieciešamas admin tiesības
- Install GitHub.cli ar komandu: winget install --id GitHub.cli --nepieciešamas admin tiesības.
- gh auth login
- gh auth status
- git config --global user.name "username"
- git config --global user.email "e-mail"
- Izveidot savu repository GitHub
- git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
- Ja nepieciešams mainīt: git remote set-url origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
- izveidot mapi uz lokālā datora.
- Esot pareizajā mapē palaist command promt
- git add .
- git commit -m "Initial commit"
- git branch -M main
- git push -u origin main


Versijām

- git tag -a v1.0.0 -m "Version v1.0.0"
- git push origin v1.0.0
- git tag
